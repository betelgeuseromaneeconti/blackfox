# BLACKFOX VPN — Android & Android TV Feature Inventory

This document catalogs every Android and Android TV feature in the repository, its native Kotlin/JNI and Flutter implementation, and how it is preserved in the BLACKFOX mobile-first Victorian Gothic redesign.

---

## 1. Android Native Architecture & VpnService Integration

| Feature | Source File(s) | Implementation & Behavior |
| :--- | :--- | :--- |
| **In-Process Go Core (`core.aar`)** | `core/mobile/mobile.go`, `app/android/app/src/main/kotlin/com/arman/firefoxvpn/CoreService.kt`, `app/lib/core/android_core.dart` | The Go Core runs inside the Android application process via `gomobile` bindings (`mobile.Mobile`). While the UI is open and disconnected, the Core runs with the proxy off so accounts, servers, and settings work immediately. |
| **Foreground VpnService & `hev-socks5-tunnel`** | `CoreService.kt`, `Tun2Socks.kt`, `app/android/hev-socks5-tunnel/` | When connected in VPN mode (`MODE_VPN`), `CoreService` requests `VpnService.prepare`, runs as a `specialUse` foreground service, creates a TUN interface (`172.19.0.1/30`, DNS `172.19.0.2`, IPv6 `fdfe:dcba:9876::1/126`, configurable MTU default 1500), excludes its own package to prevent routing loops, and runs `hev-socks5-tunnel` (`libhev-socks5-tunnel.so`) over JNI to forward TCP and supported UDP flows to the Core's loopback SOCKS5 listener. |
| **Proxy-Only Mode (`MODE_PROXY`)** | `CoreService.kt`, `AndroidCore.mode` | Runs the foreground service and local SOCKS5/HTTP proxy (`127.0.0.1:10810` or `0.0.0.0:10810` for LAN sharing) without establishing an Android `VpnService` TUN interface. |
| **Underlying Network Tracking & Roaming** | `CoreService.kt` (`watchNetwork`) | Monitors `ConnectivityManager` for the best non-VPN internet network (`NET_CAPABILITY_INTERNET` + `NET_CAPABILITY_NOT_VPN`), calls `setUnderlyingNetworks`, and notifies `mobile.Mobile.networkChanged(true/false)` so Wi-Fi <-> Mobile Data transitions reconnect immediately. |
| **Persistent Status Notification** | `CoreService.kt` (`notification`), `res/drawable/ic_stat_logo.xml`, `res/values/strings.xml` | Displays ongoing foreground notification with the monochrome BLACKFOX Kitsune icon, exit country flag and name (or `Connecting…` / `No internet connection`), optional live download/upload speed (`↓ / ↑`), proxy address when in Proxy-only mode, and a `Disconnect` (`ACTION_STOP`) action button. |
| **Quick Settings Tile (`QuickTile`)** | `QuickTile.kt`, `MainActivity.kt` (`onNewIntent`) | Toggles the VPN connection directly from Android's Quick Settings shade. If VPN permission is not yet granted, opens `MainActivity`. Long-pressing the tile (`ACTION_QS_TILE_PREFERENCES`) opens the app directly to the Home screen (`AndroidCore.homeRequests`). |
| **Home-Screen Widget (`ConnectWidget`)** | `ConnectWidget.kt`, `res/layout/widget_connect.xml`, `res/drawable/widget_button_*.xml` | 1x1 home-screen widget that toggles the VPN connection and updates its visual state (`OFF`, `CONNECTING`, `CONNECTED`) whenever `CoreService` state changes. |
| **First-Run Country & Routing Detection** | `MainActivity.kt` (`routingCountries`), `AndroidCore.prepareFirstRunRouting`, `app/lib/app_settings.dart` | During initial setup only (`settings.firstRun`), reads `networkCountryIso` and `simCountryIso` from the default data subscription (without phone-state or location permissions) and falls back to the system locale country to suggest a regional routing preset (`ir`, `cn`, `ru`, `af`, `tr`, `id`, `br`, or none). |
| **Per-App VPN Routing (Split Tunneling)** | `CoreService.kt` (`applyApps`, `suggest`), `app/lib/ui/bypass_apps_page.dart`, `AndroidCore.appRouting` | Supports `Bypass selected apps` (`MODE_EXCLUDE`) and `Proxy selected apps` (`MODE_INCLUDE`). Automatically suggests apps from the active routing region's list (`mobile.Mobile.directApps()`) unless unchecked by the user (`DECLINED`). Supports searching installed apps, showing system apps, and importing/exporting package lists via the clipboard. |
| **In-App Browser Sign-In Proxy** | `MainActivity.kt` (`setWebViewProxy`), `app/lib/ui/browser_signin.dart` | Uses `androidx.webkit.ProxyController` to route the in-app `WebView` through the Core's loopback sign-in proxy (`POST /api/signin/browser/proxy`), using the Core's encrypted DNS, multi-address fallback, and upstream proxy even before any account is added or VPN connected. |
| **Storage-Permissionless Backup Save/Open** | `MainActivity.kt` (`saveFile`, `openFile`), `app/lib/ui/backup.dart` | Uses Android Storage Access Framework (`ACTION_CREATE_DOCUMENT` and `ACTION_OPEN_DOCUMENT`) to export and import account backup `.zip` files without requesting broad storage permissions. |
| **Recent-Apps Task Deduplication** | `MainActivity.kt` (`removeOtherCards`) | Cleans up duplicate recent-app tasks created by empty `taskAffinity` when launched from the notification, Quick Settings tile, or widget. |
| **Android Backup Rules** | `res/xml/backup_rules.xml`, `res/xml/data_extraction_rules.xml` | Backs up `files/core` accounts and settings while excluding logs, caches, geo lists, and `local-api.token`. |

## 2. Android TV Dedicated Support

| Feature | Source File(s) | Implementation & Behavior |
| :--- | :--- | :--- |
| **Leanback Manifest & Banner** | `AndroidManifest.xml`, `res/drawable-xhdpi/banner.png`, `tool/app_icons.py` | Declares `android.software.leanback` (`required="false"` for universal APK, and dedicated Android TV APK) and `android.hardware.touchscreen` (`required="false"`), with `CATEGORY_LEANBACK_LAUNCHER` and a 320x180 monochrome BLACKFOX Kitsune TV banner. |
| **TV Detection & Orientation Handling** | `MainActivity.kt` (`isTv`, `holdPhoneUpright`), `AndroidCore.isTv` | Detects `UI_MODE_TYPE_TELEVISION`. Phones (<600dp width) stay portrait; tablets, foldables, and TVs allow landscape/unspecified orientation. |
| **Remote Control / D-Pad Focus & Navigation** | `app/lib/ui/focus_ring.dart`, `app/lib/ui/overview_page.dart`, `app/lib/ui/welcome_page.dart` | `FocusRing` activates automatically at startup on Android TV (`atStart: Platform.isAndroid && AndroidCore.isTv`), drawing a high-contrast monochrome focus border around the focused control when navigating with D-pad arrow keys and `OK`/`Select`. Primary actions (`Start` on Welcome, Connect orb on Home) receive `autofocus: true` on TV, and hints read `"Press OK to connect"` (`tapToConnectTv`). |
| **No-Browser URL Fallback** | `MainActivity.kt` (`openUrl`), `app/lib/ui/widgets.dart` (`openLink`, `showLink`) | Filters out `com.android.tv.frameworkpackagestubs` when checking for browser handlers; if no browser is installed on the TV, displays a dialog with the full readable URL so the user can open it on another device. |

## 3. Mobile-First UI Navigation & Screen Inventory

| Screen / Section | Required Mobile Controls & Features |
| :--- | :--- |
| **Mobile Navigation (`MobileShell`)** | Dedicated bottom navigation bar with 5 main sections: **Home**, **Servers**, **Accounts**, **Activity** (Application Logs & Connection History), and **Settings** (with Help and About accessible from Settings and header menu). Full support for Android system back button and edge back gestures (`PopScope`). |
| **Home Screen (`_PhoneHome`)** | Top bar with BLACKFOX Kitsune logo, application status pill, and quick Help/About menu button. Central circular Gothic glass Connect/Disconnect orb, VPN status label, selected server/country/city, connection duration (uptime), compact frosted glass telemetry cards (Download speed, Upload speed, Latency, Account quota, Active account, Uptime, Public IP when enabled), quick Connection Test & Restart Proxy actions, recent connection activity preview, and quick mode switcher (All apps / Selected apps / Proxy). |
| **Server Screen (`ServersPage`)** | One-handed mobile-friendly server browser with Auto Recommended, Auto Fastest, search bar, sort by Latency / Name, Test Real Delay button, Refresh action, and compact monochrome server cards with country code badge, country/city name, real latency pill, and active indicator. |
| **Account Screen (`AccountsPage`)** | Mobile-friendly account cards with priority badge, status pill, quota bar, reset date, Use Now / Sign In Again, Enable switch, move up/down & drag-and-drop reordering, Refresh quota, Remove confirmation dialog, Add Account button, Backup export/import menu, sign-in method selector, and switch threshold setting. |
| **Activity & Logs (`LogsPage` / `ConnectionsView`)** | Segmented view switching between **Application Logs** (live logs, severity filter, search, Follow/Pause toggle, detailed logs toggle, copy, clear) and **Connection History** (expandable/compact connection items showing time, destination, client, routing rule, protocol, traffic, duration, filter, follow, clear). |
| **Settings (`SettingsPage`)** | Searchable categorized subpages: **General** (Language, Theme, Show public IP, Quick VPN mode switch, Speed in notification), **Connection** (Connection mode: VPN vs Proxy only, Protocol HTTP/1.1, HTTP/2, HTTP/3, IP version, MTU, Local proxy port, Listen address, Proxy login), **DNS** (System, Auto DoH, Cloudflare, Google, Quad9, DoT, Custom, Fallback, Test DNS), **Routing** (Country preset, Per-app proxy `BypassAppsPage`, Direct routing switch, Block ads switch, Direct/Block rules, Restore regional rules, Resolve domains, Geo files source & update, Test destination), **Relay & Network Bypass** (Shared relay, Personal relay, ECH, Test relay health, TLS fragmentation, Upstream SOCKS5 proxy), **Help**, and **About** (BLACKFOX Kitsune logo, Version 1.0.3, Core version, Check for updates, Source code, Web dashboard, and `Made by Jackdaw` as the final line). |
