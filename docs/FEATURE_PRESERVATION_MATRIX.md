## 2. Dialogs & Popups Inventory

1. **`_SignInDialog` (`app/lib/ui/signin_dialog.dart`)**: Email/Password form with Autofill (`AutofillGroup`), show/hide password, multi-step Mozilla FxA verification (`need_email_code` with Persian/Arabic-Indic digit normalization `_CodeDigits`, `need_totp`, `need_unblock_code`, `need_captcha` base64 PNG decode, `need_email_link`), `no_account` sign-up link, `no_password` set-password link, browser retry callback, TV top-aligned layout.
2. **`showPortDialog` (`app/lib/ui/port_dialog.dart`)**: Prompts to replace a blocked/taken port (pre-filling a free port via `findFreePort`) or change an active port; validates `1..65535` & `isFree(port)`.
3. **`showCloseDialog` (`app/lib/desktop/close_dialog.dart`)**: Desktop close prompt (`Minimize to tray`, `Quit`, `"Remember my choice"` checkbox).
4. **`_RelayTestDialog` (`app/lib/ui/relay_test_dialog.dart`)**: Streaming step-by-step relay diagnostic test (`POST /api/relay/test` stream), live scrolling monospace report, Copy report, Retry, Close.
5. **`_showDiagnosticsDialog` (`app/lib/ui/overview_page.dart`)**: Live modal showing Connection Test Stages (`Tunnel`, `TLS`, `HTTP + status`, `Total time`, `Public IPv4`, `Public IPv6`) and Server/Account/ProxyPass telemetry (`Server host`, `Country / City`, `Transport`, `Active account`, `Ready accounts`, `ProxyPass expires`, `seconds remaining`, `Session traffic`), with `Reload`, `Test Connection`, and `Close` actions.
6. **`_showEchDialog` (`app/lib/ui/settings_page.dart`)**: Modal configuring `network.api_relay_ech` (`auto`, `required`, `off`) and `network.api_relay_ech_config` (base64 or hex custom ECHConfigList).
7. **Account Dialogs (`app/lib/ui/accounts_page.dart`)**: Switch threshold percentage dialog (`1–100%`) and Remove account confirmation dialog (`DELETE /api/accounts/{id}`).
8. **`_ImportDialog` (`app/lib/ui/backup.dart`)**: Displays account list parsed by `POST /api/backup/inspect` (highlighting already-existing emails) before confirming `POST /api/backup/import`.
9. **Settings Sub-Dialogs (`app/lib/ui/settings_page.dart`)**: Language-suggested regional routing prompt (`routingSuggestTitle`), Remove TUN service confirmation (`_removeTunService`), Running Programs picker (`GET /api/tun/programs`) + searchable list, Manual Program path/wildcard entry, and Clipboard import Replace/Merge dialog (`bypass_apps_page.dart`).
10. **No-Browser URL Dialog (`showLink` in `app/lib/ui/widgets.dart`)**: Copyable readable URL dialog when Android TV / minimal OS has no browser handler.
11. **`AnnouncementOverlay` / `AnnouncementPanel` (`app/lib/ui/announcement_panel.dart`)**: Scrim modal presenting localized manifest announcements (`once`, `per_launch`, `until_acknowledged`) with `navigate` -> Updates or `open_url` action & dismiss persistence.

| Category | Config Path / Endpoint | Allowed Values & UI Default | Behavior / Constraints |

| Connection | `proxy.transport` | `'h1'` (HTTP/1.1), `'h2'` (HTTP/2, UI fallback), `'h3'` (HTTP/3) | Selects upstream Fastly transport. Note: HTTP/3 disabled when upstream SOCKS5 proxy is enabled. |
| Connection | `proxy.ip_version` | `'auto'` (UI default), `'dual'`, `'ipv6_first'`, `'ipv4'`, `'ipv6'` | Controls IP family resolution/dialing to upstream proxy nodes. |

| Connection | `proxy.listen` (`core.setProxyPort`) | `127.0.0.1:<port>` (local) or `0.0.0.0:<port>` (LAN); default port `10810` | Local SOCKS5 & HTTP proxy listener; LAN mode unlocks `_LanChip`. |

| Routing | `routing.enabled`, `routing.region`, `routing.direct`, `routing.block`, `routing.resolve_domains`, `routing.geosite_url`, `routing.geoip_url` | Regions (`''`, `ir`, `cn`, `ru`, `af`, `tr`, `id`, `br`), rule lists, adblock `geosite:category-ads-all`, geo sources (Chocolate4U / Loyalsoldier / custom) | Supports `Restore regional rules` (`GET /api/routing`), `Update geo files` (`POST /api/routing/update`), and `Test destination` (`POST /api/routing/test`). |
| TUN | `tun.programs` | Array of `{name/path, udpOnly}` (max 200) | Desktop (`Windows`, `Linux`): bypass all traffic or UDP-only per executable (`GET /api/tun/programs`, native file picker, wildcard name). |
| Relay & Bypass | `network.shared_relay_enabled`, `network.api_relay_enabled`, `network.api_relay`, `network.api_relay_ech`, `network.api_relay_ech_config` | Booleans, `https://` URL, ECH mode (`auto`, `required`, `off`), base64/hex ECHConfigList | Bypasses network censorship for FxA/Guardian/location APIs; `POST /api/relay/test` streams health verification. |
| Relay & Bypass | `network.hello_split` | `'off'`, `'auto'` (UI default), `'first-byte'`, `'sni'`, `'record'` | TLS ClientHello fragmentation/splitting for SNI filtering bypass. |
| Relay & Bypass | `network.upstream_proxy_enabled`, `network.upstream_proxy`, `network.upstream_proxy_username`, `network.upstream_proxy_password` | Bool, `host:port`, optional credentials | Chains through an upstream SOCKS5 proxy; cannot equal own `proxy.listen`. |
| Accounts | `accounts.switch_threshold_percent` | `1..100` (default `95`) | Threshold at which quota turns red & auto-rotates to next ready account. |
| Advanced | `dashboard.listen` | `host:port` (default `127.0.0.1:10820`) | Changes Core API / Web Dashboard port (`CoreController.setApiPort`). |
| Advanced | `logging.verbose` | `bool` | Includes unredacted destination hosts in Core logs. |
