## Download

Download BLACKFOX from the official [Releases page](https://github.com/shakur4min/blackfox/releases).

Choose the package that matches your device and operating system. Use release assets published in this repository.

| Platform | Package |
| --- | --- |
| Android | APK |
| Windows | Windows release package |
| Linux | Available Linux release package |
| macOS | When a macOS release is published |
| Android TV | Compatible Android release, when provided |

Not every platform necessarily has an installer attached to every release. Check the release notes and available assets before downloading.

## Installation

### Android

1. Open the [BLACKFOX Releases](https://github.com/shakur4min/blackfox/releases) page on your device.
2. Download the Android APK from the latest release.
3. Open the downloaded APK.
4. If Android asks, allow installation from the source you used to download the file.
5. Complete the installation and open BLACKFOX.
6. When prompted to establish a VPN connection, review the Android system request and allow it if you want BLACKFOX to manage device traffic in VPN mode.

### Windows

1. Open the [BLACKFOX Releases](https://github.com/shakur4min/blackfox/releases) page.
2. Download the Windows package.
3. If the release provides an installer, run it and follow the setup instructions.
4. If the release provides an archive, extract it and follow any platform-specific instructions included with that release.
5. Launch BLACKFOX.

Some connection modes may request administrator permission to install or manage required system components. Review the request before approving it.

### Linux

1. Open the [BLACKFOX Releases](https://github.com/shakur4min/blackfox/releases) page.
2. Download the package provided for your Linux distribution and system architecture.
3. Install it using the package manager appropriate for that format, or follow the instructions included with the release.
4. Launch BLACKFOX.

The available package formats may differ between releases.

### macOS and Android TV

Use these platforms only when a compatible package is listed in the release assets. Follow any platform-specific installation notes attached to that release.

## First-time setup: Firefox Account

A Firefox Account is required before you can add an account in BLACKFOX.

1. Open the [Firefox Account registration page](https://accounts.firefox.com/signup).
2. Create a Firefox Account using an email address you can access. You can use your Gmail address.
3. Choose a password for your Firefox Account and complete the email verification steps.
4. After the account is ready, open BLACKFOX.
5. Go to **Settings** and open the **Accounts** section. If your version shows Accounts as a separate navigation item, open **Accounts** there.
6. Select **Add account** or **Sign in**.
7. Enter the email address and password for your Firefox Account.
8. Complete any additional verification requested during sign-in, such as an email confirmation code or two-factor authentication.
9. Wait until the account is added and shown as ready in BLACKFOX.

**Important:** Use your Firefox Account password when signing in to BLACKFOX. Do not enter your Gmail password unless it is also the password you independently chose for your Firefox Account. BLACKFOX does not need your Gmail mailbox password.

Once an account has been added successfully, return to the Home screen and choose your preferred connection mode and server selection.

## Connecting

1. Make sure an account has been added and is ready.
2. Open the Home screen.
3. Choose the available connection mode for your device.
4. Select a location, or use the automatic selection option if available.
5. Press **Connect**.
6. Wait for the connection status to confirm that the connection is active.

To stop the connection, press **Disconnect** in BLACKFOX.

Some modes require an operating-system permission or an administrator confirmation. These prompts are part of configuring the selected connection mode.

## Account and configuration notes

- Keep access to the email address associated with your Firefox Account so you can complete future verification requests.
- If sign-in asks for an additional code or confirmation, complete that step before retrying.
- Before reinstalling or moving to another device, use the account or configuration backup options available in the app, if provided by your version.
- Do not share account passwords, verification codes, backup files, or other private account information.

## Troubleshooting

**I cannot sign in**

- Confirm that the email address and Firefox Account password are correct.
- Check your email for a verification message or code.
- Complete two-factor authentication if it is enabled.
- If the account is temporarily blocked or verification is pending, follow the instructions shown by the sign-in flow and try again later.

**The app says that no account is available**

- Open **Settings → Accounts** (or the Accounts section in the app navigation).
- Add a Firefox Account and finish all verification steps.
- Confirm that the account is enabled and ready.

**The connection does not start**

- Confirm that the device has working internet access.
- Confirm that an account is ready.
- Try another available location or connection mode.
- Review the app's connection status and logs for additional information.
- On Android, make sure the system VPN permission was granted if VPN mode is selected.

**A platform package is missing**

- Check the latest release's assets and notes.
- A platform is available for download only when a compatible package has been published.

## Privacy and security

- Download BLACKFOX only from this repository's Releases page.
- Keep your Firefox Account password and verification codes private.
- Review operating-system permission prompts before approving them.
- Do not install packages from unofficial mirrors or unverified sources.
